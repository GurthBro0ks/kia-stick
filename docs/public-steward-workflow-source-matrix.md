Phase: `KIA-Stick-public-steward-workflow-platform-bundle-1`

Source boundary: existing exact-allowlisted, read-only cache for
`apwu-usps-cba-2024-2027`. No fetch, sync, refresh, replacement, regeneration,
or source mutation was performed.

Selection rule: a topic is `SUPPORTED` only when exact current CBA paragraphs
can support a bounded generic grievance outline while verified contract
language, unknown case facts, local rules, and conditional argument framing
remain distinct. `BOUNDED` means useful language exists but the current
national-CBA-only source is not sufficient for a full generic builder at this
scope. `INSUFFICIENT` means the cache does not contain enough directly
applicable verified authority.
